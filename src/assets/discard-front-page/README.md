# Discarded front page

This folder preserves the newer experimental landing page that was replaced by the previous iPawcus landing page.

Archived source:

- `LandingPage.jsx` is the archived entry component.
- `ModernLandingPageContent.jsx` contains the page layout and content.
- `PetStage.jsx` contains the optional Three.js pet scene.
- Supporting images and videos remain in `public/landing-media/`.
- The archived `.landing-*` styles remain grouped under `Modern landing page` near the top of `src/index.css`.

To reactivate it, point `src/components/landingpage.jsx` to `../assets/discard-front-page/LandingPage.jsx`.
