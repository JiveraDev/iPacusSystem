# IPAWCUS FigJam Board

Use `IPAWCUS-Data-Flow-FigJam-Board.svg` to import both diagrams on one FigJam canvas.

1. Open the target FigJam board.
2. Drag the SVG onto the canvas, or use the import command.
3. Keep the original aspect ratio while resizing.
4. Ungroup the imported SVG if individual vector elements need editing.

The package also includes separate context and Level 1 SVG files for importing one diagram at a time.

The imported connectors are editable vector paths. If fully native FigJam connectors are required, use the SVG paths as the routing guide after ungrouping.
